# Notes App

A full-stack notes management application built with React, Node.js, Express, and MongoDB that allows users to securely create, edit, delete, search, and pin their personal notes.

## Features

- 🔐 User authentication with JWT
- 📝 Create, edit, and delete notes
- 📌 Pin and unpin notes
- 🔍 Search notes by title, content, or tags
- 🏷️ Add and manage tags for notes
- 👤 Display authenticated user information
- 🔒 Users can access and manage only their own notes
- ⚠️ Handle authentication errors and invalid requests
- 📱 Responsive design for different screen sizes

## Usage

1. Create an account using your name, email, and password.
2. Log in to access your notes dashboard.
3. Click the **+** button to create a new note.
4. Add a title, content, and optional tags.
5. Edit or delete notes using the available actions.
6. Pin important notes to keep them at the top.
7. Use the search bar to find notes by title, content, or tags.
8. Log out when you're finished.
